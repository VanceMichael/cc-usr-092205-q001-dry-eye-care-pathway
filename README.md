# 干眼风险分层随访

支持干眼筛查、风险分层、复查转诊和跨机构连续照护。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块统一加载这些资料，并校验领域标识、版本、参与方、事实和约束等必要字段。

当前资料反映以下领域事实：

- 干眼由泪液质量、数量和动力学等多因素共同引起
- 儿童青少年和职场人群发病呈年轻化趋势
- 持续症状或中重度炎症需要规范就医而非盲目滴药
- 长期盯屏员工易把异物感和视力波动当作普通疲劳，自行换药可能掩盖需转诊的炎症或角膜风险
- 连续照护记录整合问卷、工作环境、用眼习惯、既往疾病、长期用药、泪膜检查和医生判断
- 判断只追加不改写，并记录所依据的分层规则版本
- 企业筛查转医院时按身份去重，雇主仅见群体风险，个体信息需本人授权

## 本地校验

运行项目自带测试可确认样例资料符合约定。仓库不保存账号、密钥、连接串或真实身份资料。
